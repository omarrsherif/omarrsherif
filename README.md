## 🚀 Featured Projects

### [Concurrent Cache API](https://github.com/omarrsherif/go-cache-api)
**Go · Redis · MySQL · Docker · HTTP**

- RESTful CRUD API over MySQL with a Redis **cache-aside** layer: TTL expiry, invalidation on write, request coalescing.
- Go concurrency, connection pooling, structured errors, health checks, graceful shutdown; Docker Compose and CI.
- Repo benchmark (single host): p99 latency 55.4 ms → 2.4 ms and throughput 24k → 65k req/s at 50 clients.

### [EDGAR Fundamentals](https://github.com/omarrsherif/edgar-fundamentals)
**Python · DuckDB · Streamlit**

- Loads eight quarters of SEC 10-K/10-Q XBRL facts into a DuckDB warehouse.
- 22 data-quality rules, a 13-ratio layer, and a Streamlit dashboard linking every figure to its filing.

### Multilingual Multi-Agent AI System
**Python · LLMs · NLP · Multi-Agent Architecture** · University of Minnesota senior design

- Accepts requests in multiple languages, translates them, and routes each to a specialized agent for translation, summarization, question answering, or speech-to-text.
- Benchmarked **BART-large-MNLI** vs **Llama 3.1 8B** for intent routing: ~91% vs ~99% on a preliminary 200-prompt set. Now expanding the benchmark and measuring runtime cost.

### [ShopAdmin](https://github.com/omarrsherif/shop-next-public)
**TypeScript · Next.js · Supabase · PostgreSQL**

- Order-management app for a resale business: catalog, customer orders, a receiving → packing → shipping pipeline, Arabic shipping slips, and an analytics dashboard with a full audit trail.
- Next.js App Router with Server Components and Server Actions on Supabase (Postgres, Auth, Storage); rewrite of a legacy Flask app, tested with Vitest and Playwright.

### Spatial Indexing & Trajectory Data Research
**Databases · Quadtrees · Hierarchical Spatial Partitioning** · University of Minnesota

- Investigating hierarchical spatial partitioning: quadtrees, pyramid indexing levels, cell subdivision.
- Reviewing how large spatial and trajectory datasets are organized for ingestion. Ongoing research, not a released system.
